# Zion AI Meeting Copilot

AI copilot for meetings: live transcription summaries, action-item extraction, decision logs, and follow-up drafting. Standalone app in the Zion Tech Group app network.

- Live app: https://meeting-copilot.ziontechgroup.com
- Landing page (GitHub Pages): https://zion-support.github.io/zion-ai-meeting-copilot/

## Features

- Real-time meeting transcription digest and topic segmentation
- Automatic action items with owners and due dates
- Decision log with timestamps and context links
- One-click follow-up emails and CRM notes
- Calendar-aware briefs before each meeting
