# Zion AI Meeting Copilot

AI meeting copilot for Zoom/Google Meet/Teams: live transcription, summaries, action items, CRM sync. Standalone app in the **Zion Tech Group App Network**.

- Live app: https://meeting-copilot.ziontechgroup.com
- Network hub: https://zion-support.github.io/zion-network/
- Main site: https://ziontechgroup.com · Apps hub: https://ziontechgroup.com/apps/

## Features
- Real-time transcription and speaker attribution
- Auto summaries, decisions, and action items pushed to your stack
- Pair with [Zion AI Voice Assistant](https://github.com/Zion-support/zion-ai-voice-assistant) for voice-first workflows
- Automate follow-ups with [Zion AI Workflow Automator](https://github.com/Zion-support/zion-ai-workflow-automator)
- Turn meeting notes into posts with [Zion Content Studio](https://github.com/Zion-support/zion-content-studio)
